# Clipper (privado, local)

Pega un link de YouTube → propone los momentos más repetidos → genera clips editados (vertical, subtítulos, título, velocidad).

```bash
pip install -U yt-dlp      # y tener ffmpeg instalado
python servidor.py         # abre http://127.0.0.1:8765
```

Solo escucha en tu ordenador (127.0.0.1). Los clips quedan en `clipper/clips/`.
